◆ ctr_lte_v2_send_recv()

int ctr_lte_v2_send_recv ( const struct ctr_lte_v2_send_recv_param *  param)

Send data and optionally receive response.

Sends data to the network and optionally waits for a response.

The LTE stack works on its own copy of param. When the timeout expires before the exchange has ended, the call gives the exchange up and returns -ETIMEDOUT; the stack goes on with what it is doing (for example the network attach). If the modem is just then exchanging the data with the caller's buffers, the call first waits for that AT dialog to end, which can take up to about 36 s past the timeout; a response received in that wait is dropped. The result follows who ended the exchange, not the time: an exchange the stack has completed returns 0 even when that happened just past the timeout.

The buffers in param are not touched after the call returns.

After -ENOTCONN for a missing connection, 'lte state' shows the extended error report of the modem (AT+CEER).

Parameters
paramSend/receive parameters (see ctr_lte_v2_send_recv_param).
Return values
0Success.
-ETIMEDOUTThe exchange did not end before the timeout, or the response did not come.
-ENOTCONNLTE is disabled, the socket is not usable, or the network granted no connection for the data (see ctr_lte_v2_send_recv_param::retry_count).
-EBUSYAnother exchange kept the stack busy until the timeout.
-ENOTSUPTest mode is enabled.
-EINVALparam is NULL, or has recv_buf without recv_size or recv_len.
